# AI-Powered Library Management System

This is a Streamlit-based application for managing a library with AI features including semantic search, personalized recommendations, and admin analytics.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run streamlit_app.py` 

## Features
- **Semantic Search**: Find books based on natural language queries.
- **Recommendations**: Content-based filtering using TF-IDF.
- **Admin Panel**: Monitor inventory and system health.
